C 與 C++ 的輸入輸出對照

iClass 的 Hello World 範例以 .cpp 提供。下方用一支自編程式對照兩種寫法。C 的 scanf 透過位址寫入變數，C++ 的 std::cin 直接接收變數，用串流狀態檢查讀取是否成功。

#include <iostream>

int main() {
    int n;
    if (!(std::cin >> n)) return 1;
    std::cout << n << '\n';
    return 0;
}

把此例另存成 main.cpp，使用 c++ -std=c++17 -Wall -Wextra main.cpp -o main 編譯。這七課示範的條件、迴圈和陣列基本概念同樣適用。
