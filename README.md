# 程式語言（一）｜C 語言練習室

[開啟公開學習頁](https://rtxmythically.github.io/programming-language-study-notes/)

繁體中文的 C 語言互動學習頁。前七課依淡江大學 115 學年度第 1 學期資工一 B 班公開教學計畫排列，包含基本結構與輸入輸出、型別、條件、選單、迴圈、跳轉與陣列。

每課可逐步追蹤範例、預測輸出並核對答案。另有八題自編實作，以及依 iClass 10/12、11/3 練習和第 3、6、7 週作業重寫的六題同型題。各題提供範例輸入輸出、邊界提示、可下載草稿與參考解法。答案預設收合，草稿及完成進度保存在瀏覽器。

2026/11/08 核對 iClass B 班當日可見內容。新增 28 筆教材、55 個附件的可搜尋索引與重點說明、七週作業的 20 項摘要，以及兩次公告的 7 道課堂練習。10/19 小考與第 5 週作業共用同一組整理。另有七支可下載的自編 C++ 補充範例。原始附件及題目全文連回 iClass。

直接開啟 index.html 即可使用，頁面無外部套件。網站中的追蹤器用固定範例示範執行順序，自寫的程式可下載後使用 C17 編譯器測試。
